# 韩语翻译审查

本分支包含韩语国际化、逐条审查后的译文和中韩对照页。

## 在其他机器上打开

克隆此分支后，用浏览器打开 `docs/i18n/ko-zh-review.html`：

```sh
git clone --branch codex/korean-localization --single-branch https://github.com/cuiyf5516/cc-switch.git
```

也可以在 GitHub 的此分支页面选择 **Code → Download ZIP**，解压后打开同一文件。请保留同目录的 `ko-review-controls.js`，标记功能需要它。无需安装项目依赖或运行应用。

GitHub 的文件预览不会运行 HTML 中的交互功能。只想阅读文本时，可查看 [Markdown 对照](ko-zh-review.md) 和 [审查说明](ko-review-notes.md)。

## 标记与跨机器转移

在对照页右侧勾选“待复审”并添加备注，点击“导出待复审 JSON”，将文件交给助手进行二次审查。确认译文后可勾选“已审查”；它与“待复审”互斥，都不勾选表示未审查。工具栏可分别筛选待复审和已审查项，并显示各状态的数量。

“只看未标记”显示既未勾选“待复审”、也未勾选“已审查”的条目，包括保留了备注但取消两种标记的条目。三个复审状态筛选互斥，并可与搜索和“只看修订项”组合使用。

输入备注时仍会自动保存并标为待复审；正在编辑的条目会暂时保留显示，离开备注框后再按复审状态筛选，避免输入过程中条目突然消失。

标记保存在各机器的浏览器本地存储中，不随 Git 自动同步。换机器前请点击“导出全部审查状态”，在另一台机器的对照页中点击“导入标记 JSON”恢复。备注和已审查状态均会保留。旧版仅包含待复审标记的 JSON 仍可导入。浏览器提示无法本地保存时，请在离开页面前导出。

如果某条已审查译文在页面更新后发生变化，它会重新变为待复审，并保留原备注。导入已审查状态时也会校验对应的韩文译文。
